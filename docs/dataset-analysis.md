# Dataset Analysis & Statistical Insights

## 1. Alumni Network Distribution (1,000 Records)
- **Placement Rate**: 88% Direct Industry Placement, 12% Higher Studies (MS/MBA/M.Tech).
- **Average Starting Package**: ₹8.4 LPA overall, ₹14.6 LPA for AI/ML/Data roles.
- **Top Hiring Companies**: Google, Microsoft, Amazon, Flipkart, Infosys, TCS, Deloitte, Oracle.
- **Top Domains**:
  - Full Stack & Web Engineering (38%)
  - AI, Data Science & Machine Learning (32%)
  - Cloud & DevOps Infrastructure (18%)
  - Cybersecurity & Systems (12%)

## 2. Skill Correlation & Industry Demand
- Most frequent paired skills: `Python + SQL`, `React + Node.js`, `Docker + AWS`, `PyTorch + Machine Learning`.
- Core prerequisites with highest hiring correlation:
  1. Data Structures & Algorithms (88% required across software tracks)
  2. Problem Solving & Clean Code (92%)
  3. Git & Distributed Version Control (85%)
